# 🌐 Public Project Showcase & Website

This directory contains public marketing web pages, community roadmap showcases, and online preset QR code generators intended for deployment on public domains (e.g., `thepurplefox.site/public_cam_idea.php`).

## 🎯 Purpose & Scope

- **Environment**: Public web servers (Apache, Nginx, PHP 8.x).
- **Design Philosophy**: Standalone, SEO-optimized, responsive public showcase page explaining the project, roadmap, hardware matrix, and community support channels.

## 📌 Included Files

- **`public_cam_idea.php`**: Master public blueprint & idea showcase page (PHP + Tailwind CSS + Sirv CDN integration + Schema.org JSON-LD structured data).
- **`camera_app_ideas.html`**: Interactive standalone HTML roadmap prototype.
- **Preset QR Code Generator**: Online tool for generating encrypted setup QR codes to pair new nodes without manual typing.
