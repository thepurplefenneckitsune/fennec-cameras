# 📱 Mobile Node & Touch Control UI

This directory contains the lightweight, touch-first mobile interface designed specifically for phone camera nodes and touch screen controllers.

## 🎯 Target Hardware & Use Case

- **Environment**: Old Android smartphones, tablets, and dedicated handheld touch controllers.
- **Design Philosophy**: Minimalist, high-contrast, touch-optimized UI. Avoids heavy server desktop widgets that feel clunky or resource-heavy on phones.

## 📌 Core Capabilities

- **Lightweight Touch Controls**: Quick toggles for camera stream, torch/flash night light, dual-lens (front + rear) preview, and 360° panoramic view.
- **Battery & Thermal Monitoring UI**: Displays battery temperature, charge limiting status (50-60% swell protection), and thermal throttling state.
- **One-Scan Setup QR Scanner**: Camera viewfinder interface to scan setup QR codes from the server or web portal for instant zero-touch pairing.
- **Kiosk Mode Overlay**: Touch-screen security overlay requiring Master PIN / password to exit phone camera mode.
